## Guidance

Collapsible reveals and hides a block of content from a single trigger. `variant` is an emphasis ranking with only `default`. The chevron uses the same open rotation contract planned for Accordion: `transition-transform duration-200` and `group-data-[state=open]:rotate-180` on a 16px icon (`size-4`, stroke 1.33px).

<Canvas of={CollapsibleStories.Default} />

## When to use / When not to use

Use Collapsible for optional detail sections, repository lists, or filter groups controlled by one heading row.

Do not use Collapsible for exclusive sections (Accordion), navigation menus, or modal content.

## Do / Don't

**Do**

- Pass `disabled` on `Collapsible` to disable the trigger. The trigger sets the native `disabled` attribute when composed as a button.
- Keep the chevron `aria-hidden`. The trigger text names the control.
- Match Accordion chevron rotation when Accordion lands: do not introduce a second rotation pattern.

<Canvas of={CollapsibleStories.AsChild} />

**Don't**

- Don't use Collapsible for multi-panel exclusive expand. That belongs on Accordion.
- Don't rotate the chevron with a bespoke class outside `group-data-[state=open]:rotate-180`.
- Don't fake disabled with opacity alone.

## Accessibility in practice

The trigger is a `button` by default. Space and Enter toggle the panel. Focus uses `shadow-focus` on the trigger row. Content is shown or hidden with Radix `data-state`; it remains in the DOM.

## Content guidelines

- Write the trigger as a summary of the hidden block.
- Keep nested rows to one line where possible.
- Do not nest another collapsible trigger inside content without a clear heading.
