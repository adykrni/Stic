## Guidance

Dialog interrupts the page for a short decision. `variant` is not a status. There is one emphasis, `default`. Success, warning, and error belong on Badge or Alert, not on this surface.

<Canvas of={DialogStories.Default} />

## When to use / When not to use

Use Dialog when the person must read something and confirm or cancel before going back to the page.

Do not use Dialog for a hint. That is Tooltip. Do not use it for a notice that can wait. That is Toast. Do not use it for a choice that can stay on the page. That is Radio Group or Select.

## Do / Don't

**Do**

- Give every dialog a `DialogTitle`. Radix uses it as the accessible name.
- Put the dismiss control on the shared `Button`, `variant="ghost"` and `size="icon"`, through `DialogClose`. Do not restyle a plain element into a close control.
- Let Radix own the focus trap, the portal, and Escape. This component adds no focus or key logic.

**Don't**

- Don't draw a second overlay colour. The Dialog page has no overlay specimen. The scrim is the existing primitive `--ori-colour-primary-alpha-900-60`.
- Don't shrink the shared Button to the 16px Figma close glyph. The glyph inside the button is 16px. The button itself stays `size-10` (40px), which is the Button component on this branch.
- Don't add `loading`. Dialog does not start an action that stays in progress.

## Accessibility in practice

Focus stays inside the dialog while it is open. That trap belongs to Radix Dialog. Closing the dialog, with the close button, Cancel, or Escape, returns focus to the trigger. This component does not move focus itself.

The surface uses `focus:outline-none` because Radix focuses the content on open. The close button keeps the shared Button focus style, `focus-visible:border-ring`.

Keyboard behavior is Radix Dialog. Tab cycles through the close button and the footer actions. Escape closes. A disabled close button is not in the tab order. There is no icon-only trigger. The close glyph is `aria-hidden`, and the button's name is "Close".

## Content guidelines

- Title is a short noun phrase: "Dialog title".
- Description is one sentence. The measured description is "This is a dialog description."
- Footer actions are verbs: "Cancel", "Save changes". Cancel closes. The primary action does the work.

## Token trail

- **surface.** Width of the Figma frame is 425px. There is no spacing primitive at 425, so `max-w-[425px]` keeps the measured frame and is not rounded to another step. Padding `spacing-24`. Gap `spacing-16`. Radius `radius-10` (10px, not 8 or 12). Border `border` → `neutral-200`. Fill `background` → `secondary-50`. Shadow `shadow-dialog`.
- **scrim.** `--ori-colour-primary-alpha-900-60`, Primary 900 at 60%. Layer `z-index-400`. The dialog surface is `z-index-500`.
- **title.** Geist SemiBold `font-size-18`, line-height 100%, `foreground` → `neutral-950`.
- **description.** Geist Regular `font-size-14` / `line-height-20`, `neutral-500` (`base/muted-foreground`).
- **header gap.** `spacing-6`.
- **footer.** Gap `spacing-8`. The large breakpoint lays the actions in a row. The small breakpoint stacks them; the gap and the buttons are the same. Footer actions are the shared Button, whose default height on this branch is 40px. The Figma footer row is 36px.
- **close.** 16px from the top and the end of the frame. The glyph is 16px. The hit target is the shared ghost icon Button.

## Props

`DialogContent` is the documented component. Docgen lists `variant`, `size`, and `children`. Both axes include `null` because `VariantProps` allows it. The only keys are `default`, set in `dialogVariants`. `Dialog`, `DialogTrigger`, `DialogPortal`, `DialogOverlay`, `DialogTitle`, `DialogDescription`, and `DialogClose` are the other parts. Overlay and content render through Radix Portal.
