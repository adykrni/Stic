## Guidance

Dropdown Menu exposes actions in a portal-mounted list. Shared item styling lives in `menu-item.tsx` for Context Menu and Menubar reuse.

<Canvas of={DropdownMenuStories.Default} />

## When to use / When not to use

Use for command lists opened from a button. Use Context Menu for viewport right-click. Use Menubar for persistent horizontal menus.

## Do / Don't

**Do**

- Import item classes from `./menu-item` in sibling menu components; do not fork item colours.
- Use `defaultOpen` in docs canvases only; production menus should rely on Radix open state.

<Canvas of={DropdownMenuStories.AsChild} />

**Don't**

- Don't use Dropdown Menu as a hover surface.
- Don't duplicate `menuItemVariants` in Context Menu PRs; copy `menu-item.tsx` byte-identical until Dropdown merges.

<Canvas of={DropdownMenuStories.States} />

## Accessibility in practice

Arrow keys move between items. Escape closes the menu and returns focus to the trigger. Typeahead is provided by Radix.

## Content guidelines

- Label items with verbs.
- Keep shortcuts in `DropdownMenuShortcut`.
- Group with `DropdownMenuLabel` and `DropdownMenuSeparator`.
