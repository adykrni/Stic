## Guidance

Aspect Ratio holds content at a fixed width-to-height ratio. `variant` is an emphasis ranking, and this component has only `default`. The ratio is a number (`width / height`), not a variant. It does not carry status. Success, warning, and informational status belong on Badge or Alert.

## When to use / When not to use

Use Aspect Ratio for media and frames that must keep a proportion: a 16:9 video, a square avatar crop, a 4:3 thumbnail.

Do not use it to style the content. The frame has no fill, border, or radius. Put color on the child. Do not use it as a card.

## Do / Don't

**Do**

- Pass `ratio` as width divided by height. `1` is square. `16 / 9` is widescreen. The default is `1`, which is Figma's first ratio.
- Let the frame fill its parent. Figma's samples are 240px wide because that is the artboard, not a fixed component width.
- Put one child in the frame. The child should fill the frame (`h-full w-full`).

**Don't**

- Don't add hover, active, disabled, focus, or loading. The frame is layout only.
- Don't pass `asChild`. It is not an interactive control.
- Don't encode the Figma ratio names as `variant` keys. Ratio is not emphasis.

## Accessibility in practice

The root is a `div`. It is not focusable, so it has no keyboard behavior and does not use `focus-visible:border-ring`. PATTERNS.md specifies that ring for interactive controls. This one is not interactive. Name the content, not the frame: an image needs `alt`, and decorative media needs `alt=""`.

## Content guidelines

- Describe the media in the child's accessible name.
- Do not put a ratio label in the product UI. The story labels exist so the frames are visible.
- Crop or fit the child inside the frame. The frame does not letterbox on its own.

## Token trail
