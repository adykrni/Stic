## Guidance

Command is a filterable list with keyboard navigation, built on **cmdk**. Use it inside dialogs, popovers, or standalone palettes. `variant` is only a layout rank today (`default`).

<Canvas of={CommandStories.Default} />

## When to use / When not to use

Use Command when users pick one action or value from a searchable list with arrow-key navigation. Use Combobox when the same list sits in a Popover behind a trigger showing the current value.

Do not rebuild fuzzy search or keyboard routing by hand. Do not use Command as a generic scrollable list without filter semantics.

## Do / Don't

**Do**

- Compose with `CommandInput`, `CommandList`, `CommandEmpty`, `CommandGroup`, and `CommandItem`. Group headings use the shared menu label styles.
- Rely on cmdk for filtering, highlighting, and Enter to select. Escape closes when Command is inside a Radix Popover or Dialog.
- Mark disabled rows with the `disabled` prop on `CommandItem`.

**Don't**

- Don't duplicate `menu-item` colors on Command items; `CommandItem` uses `data-[selected=true]:bg-accent` for keyboard highlight.
- Don't omit `CommandEmpty` when filtering can return zero rows.

## Accessibility in practice

The filter field is a native text input inside cmdk. Items are `role="option"` with `aria-selected` driven by cmdk. Disabled items use `data-[disabled=true]` and `opacity-50`. Arrow keys move highlight; Enter activates the highlighted item.

Focus on the input uses the shared transparent border plus `focus-visible:border-ring` when nested inputs inherit focus styles from a parent field. Command root is not a single tab stop; tab into the input first.

## Content guidelines

- Placeholder: short instruction ("Type a command or search…").
- Group headings: one or two words ("Suggestions", "Settings").
- Empty state: "No results found." (matches Figma Command empty variant).
