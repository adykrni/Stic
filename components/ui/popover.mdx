## Guidance

Popover surfaces contextual content next to a trigger on click. `variant` is an emphasis ranking, and this component has only `default`. It does not carry status. Success, warning, and informational status belong on Badge or Alert.

<Canvas of={PopoverStories.Default} />

## When to use / When not to use

Use Popover for compact forms, filters, or short explanations that should stay near the control that opened them. Pair `PopoverTrigger` with Button or another focusable control.

Do not use Popover for navigation menus (Dropdown Menu or Menubar), hover previews (Hover Card), modal tasks (Dialog), or persistent layout (Card).

## Do / Don't

**Do**

- Control open state with `open` and `onOpenChange` when the caller must sync with other UI. Radix handles dismiss on outside click and Escape by default.
- Pass `side`, `align`, and `sideOffset` on `PopoverContent` when the default placement collides with the viewport. The default `sideOffset` is 4px (`spacing-4`).
- Use `PopoverAnchor` when the content should align to an element other than the trigger.
- Compose `PopoverClose` with `asChild` onto a Button when the panel needs an explicit dismiss control.

<Canvas of={PopoverStories.AsChild} />

**Don't**

- Don't trap focus inside the popover. It is not a dialog. Screen readers still treat it as non-modal floating content.
- Don't use Popover for hover-only content. Use Hover Card instead.
- Don't remove the border or shadow to make the panel look like inline copy. The measured surface is a bordered card with elevation.
- Don't fake a disabled trigger with `pointer-events-none` alone. Disable the actual trigger control.

## Accessibility in practice

The trigger is a native button when composed with Button and `asChild`, or the element you merge onto. It receives focus with the same `shadow-focus` treatment as other controls when focused. Escape closes the open popover and returns focus to the trigger. Tab moves through focusable elements inside the content without trapping.

Radix sets `data-state` on the content for open and closed. There is no separate `aria-expanded` requirement on the content itself; the trigger exposes expanded state.

Icon-only triggers need `aria-label` on the trigger element. The popover content does not add a title automatically.

## Content guidelines

- Keep body copy short. The default width is 320px (`w-80`), matching Figma.
- Start with a short heading when the panel has multiple fields.
- Put the primary action inside the panel, not on the trigger label.

## Props

The table is generated from `PopoverContent` props intersected with `popoverVariants`. Docgen lists `variant` and `size`. Both include `null` because that is what `VariantProps` allows; both default to `default` in `popoverVariants`. Radix props such as `side`, `align`, `sideOffset`, and `collisionPadding` come from `@radix-ui/react-popover` and may not all appear in the table. `Popover`, `PopoverTrigger`, `PopoverAnchor`, `PopoverClose`, and `PopoverArrow` re-export the matching Radix parts.
